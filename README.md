A Modern Gui that combines esp32's timing clock with output of mitutoyo displacment devices for speed calibrations.

Ability to copy and paste values with one click
Auto Stop and Live Displacment Percent Error
Can add time while test is running
Status - Live, No Signal, Connected, Disconnected
